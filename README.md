# Sunday Football Team Generator

A single-page app for splitting a roster of players into random teams for a Sunday kickabout.

Live site (once GitHub Pages is enabled): https://zerico007.github.io/sunday-football-team-generator/

## Features

- Add, remove, and toggle players (roster is saved in your browser's localStorage)
- Split into 2, 3, or 4 teams
- Team naming themes: match bibs, classic, pro clubs, or shirts vs skins
- Copy the lineup in a WhatsApp-friendly format

## Running locally

Open `index.html` in a browser. No build step is needed.
